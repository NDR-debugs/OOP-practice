## Remotes

| Remote     | URL                                               | Purpose                          |
|------------|---------------------------------------------------|----------------------------------|
| `origin`   | https://github.com/NDR-debugs/OOP-practice.git    | Your fork — `git push` goes here |
| `upstream` | https://github.com/DDC-endpoint/OOP-practice.git  | Original repo — pull updates     |

## Common commands

Push your changes to your fork:

```bash
git push origin main
```

Pull the latest changes from the original repo:

```bash
git fetch upstream
git merge upstream/main
```

Then update your fork on GitHub:

```bash
git push origin main
```
